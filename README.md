# AI Ice Dancer 🏆

An AI-powered ice dance coaching application designed to revolutionize training and judging through advanced computer vision and machine learning technology.

## 🎯 Overview

AI Ice Dancer is a cutting-edge application that combines artificial intelligence with the art of ice dance to provide:

- **Real-time technical analysis** of ice dance elements
- **Objective data support** for judges and coaches
- **Comprehensive progress tracking** for athletes
- **Advanced motion capture** and performance analytics

## ✨ Key Features

### For Athletes
- **Technical Element Analysis**: Automated recognition and analysis of ice dance elements with real-time error detection
- **Program Component Analysis**: AI-powered assessment of skating skills, transitions, performance, and composition
- **Real-time Feedback**: Instant visual and auditory feedback during training sessions
- **Progress Tracking**: Comprehensive analytics and historical data to track improvement over time

### For Judges & Coaches
- **Objective Data Support**: Automated element identification and technical overlays for consistent judging
- **Judge Training**: Simulated judging sessions and error identification training modules
- **Performance Analytics**: Detailed metrics and visualization tools

## 🛠 Technology Stack

- **Frontend**: React 18 with Vite
- **Styling**: Tailwind CSS with custom design system
- **UI Components**: Custom component library with shadcn/ui patterns
- **Icons**: Lucide React
- **AI/ML**: Computer Vision (OpenCV, TensorFlow), Machine Learning (PyTorch)
- **Cloud**: AWS, Azure, Google Cloud (planned)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd icedancer
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to `http://localhost:5173` to view the application

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
